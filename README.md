# 我的第一个项目

这是我的第一个 GitHub 项目，用来练习 Git 和 GitHub 的基本操作。

## 它是什么

一个单文件的个人主页：`index.html`，纯 HTML + CSS，没有依赖，双击就能打开。

## 怎么运行

不需要安装任何东西，直接用浏览器打开 `index.html` 就可以了。

## 我学到了什么

- 本地仓库（`git init`）
- 提交（`git add` + `git commit`）
- 远程仓库（`git remote add`）
- 推送（`git push`）

## 在线预览

部署 GitHub Pages 之后，地址会是：

```
https://你的用户名.github.io/仓库名/
```
